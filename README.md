# ToolVisuals

Клиентский мод Fabric: настраиваемый HUD, визуальные эффекты, плащи, косметика и внутриигровое меню. Открытие меню — правый Shift; клавишу можно изменить в управлении Minecraft.

Разработка: **[2twofactorauth3-star](https://github.com/2twofactorauth3-star) + [OpenAI Codex](https://openai.com/codex/)**. ToolVisuals создаётся с помощью ИИ (AI-assisted).

| Minecraft | Java | Fabric Loader | Клиентский JAR |
| --- | --- | --- | --- |
| 26.3 | 25 | 0.19.5+ | ToolVisuals-1.4+fabric-26.3.jar |
| 1.21.11 | 21 | 0.19.5+ | ToolVisuals-1.4+fabric-1.21.11.jar |
| 1.21.4 | 21 | 0.19.3+ | ToolVisuals-1.4+fabric-1.21.4.jar |

Установите Fabric Loader из таблицы или новее и один JAR под свою версию Minecraft. Fabric API и зависимости уже включены в готовые клиентские сборки.

Диагностика Discord RPC: `.toolvisuals rpc` показывает состояние подключения и записывает подробности в стандартный `logs/latest.log`. `CONNECTED` означает, что Discord подтвердил нашу активность; выбор отображаемой активности остаётся за Discord. При конкуренции с Lunar отключите **Discord Rich Presence** в настройках его лаунчера ([инструкция Lunar](https://www.lunarclient.com/news/how-to-use-the-new-lunar-client-launcher)). Ошибка определения версии через ViaFabricPlus не отключает RPC: используется родная версия Minecraft.

## Функции

В таблицах указан постоянный ID, который передаётся в API HolyWorld. «По API» означает, что функция доступна, пока сервер не запретил её своим ответом. Это техническое состояние, а не подтверждение допуска администрацией. «Выключен» — функция принудительно выключена и скрыта на HolyWorld; причины приведены ниже.

Подключаемые функции могут быть дополнительно ограничены серверным API. Учётные записи, файлы, ключи и личные настройки игрока не передаются в запросе ограничений: он содержит случайный ID запроса, идентификатор `toolvisuals` и список ID функций. Синхронизация плащей, косметики, эмоций и сетевых мини-игр — отдельный протокол плагина ToolVisuals; LiteAPI его не заменяет.

Оптимизационная база включает совместимые с целевой версией компоненты Sodium, ImmediatelyFast, EntityCulling, Lithium, FerriteCore и другие закреплённые зависимости. Точный состав, версии и контрольные суммы находятся в манифестах сборки; условия распространения перечислены в [NOTICE](NOTICE). Встроенные оптимизации не являются обещанием определённого количества FPS.

## HolyWorld

Интеграция использует официальный канал `liteapi:feature-control` и метод `checkFeatures`. При подключении отправляется список модулей, пяти дополнительных функций с ID из таблицы и фильтров NoRender. Для фильтров используется вид `no_render.<ID фильтра>`: например, `no_render.fog`, `no_render.water_overlay`, `no_render.fire_overlay`, `no_render.hurt_camera`. Полный перечень фильтров находится в [RenderOption.java](src/main/java/ru/he3hauka/toolvisuals/client/render/filter/RenderOption.java).

Ограничения включаются до ответа API на адресах `holyworld.ru`, `holyworld.me` и их поддоменах. На других адресах поддержка API или корректный ответ с ID текущего запроса также включает защиту. Проверки относятся к текущему подключению, не записывают запреты в пользовательский конфиг и сбрасываются при выходе. Просроченные ответы другого подключения игнорируются. Неуспешный ответ или таймаут не снимает уже действующие ограничения. Запросы повторяются ограниченно; после успешного обмена список обновляется раз в минуту.

| Keybinds | Предосторожность до согласования командных и чат-макросов. Ванильная настройка клавиш остаётся доступной. |
| ToolPresents | Предосторожность: помощник отдельного события ToolRise содержит автоматическое выполнение команды перехода. |
| NoRender: туман и подводный оверлей | Закрывают альтернативный способ получить отключённый эффект NoFluid. Остальные фильтры управляются отдельно через API. |

Пункты с пометкой «предосторожность» — ограничения ToolVisuals до согласования, а не утверждение об отдельном официальном запрете каждого названия. Серверный `blocklist` может запретить дополнительные функции; он всегда дополняет обязательный локальный список. Запрещённые функции не работают из меню, биндов, команд, конфигов или предпросмотра и скрываются из интерфейса, включая их клавиши в настройках управления.

Эквивалентные способы включить эффект также учитываются: запрет NoFluid закрывает соответствующие фильтры NoRender, запрет NoHurtCam — альтернативные фильтры камеры, запрет NoSwing — скрытие взмахов через CustomHand.

**ToolVisuals пока не объявлен одобренным клиентом HolyWorld.** Для рассмотрения администрация просит видео работающей интеграции на сервере, список ID функций, ссылку на проект и открытый GitHub. Наличие API и ограничений само по себе не означает допуск. ItemScroller/MouseTweaks отдельно разрешены в опубликованных правилах; итоговая доступность функций учитывает ответ API.

Проверить состояние обмена можно командой `.toolvisuals holyworld`: она различает подтверждённый ответ API и работу только локального списка ограничений.

Источники: [требования к визуалам](https://mods.holyworld.me/visuals), [официальный пример LiteAPI](https://github.com/HolyWorldMC/liteapi-fabric-example), [правила Лайта](https://github.com/HolyWorldMC/wiki/blob/main/docs/lite-anarchy/rules.md), [правила Прайма](https://github.com/HolyWorldMC/wiki/blob/main/docs/prime-anarchy/rules.md), [правила Альфа СМП](https://github.com/HolyWorldMC/wiki/blob/main/docs/alpha-smp/rules.md).

## Сборка

Нужны JDK 25, JDK 21, Python 3.10 или новее и доступ к интернету. Gradle скачивается через Wrapper. Зависимости скачиваются с официальных адресов из закреплённых манифестов с проверкой размера и SHA-512.

```shell
python build-tools/dependencies.py
./gradlew build
```

На Windows используйте `py -3 build-tools/dependencies.py` и `gradlew.bat build`. Если команда `python` недоступна, передайте Gradle путь к Python через `-PpythonExecutable=путь`.

Три клиентских JAR появятся в `build/libs`. Для отдельной версии: `./gradlew :minecraft1214:build` или `./gradlew :minecraft12111:build`. Команда `./gradlew release` дополнительно соберёт серверный плагин `ToolVisualsPlugin-1.4.jar` для Paper/Folia. Он нужен для серверной синхронизации поддерживаемых социальных функций.

Общий код находится в `src/main`, адаптеры — в `versions/common/main` и `versions/<minecraft>/main`, исходники серверного плагина — в `server/paper/src/main`. Исходник Windows-помощника MusicHUD находится в `native/music/windows`; его можно пересобрать командой `python native/music/windows/build.py` на Windows 10/11.
