# ToolVisuals


Клиентский мод Fabric: настраиваемый HUD, визуальные эффекты, плащи, косметика и внутриигровое меню. Открытие меню — правый Shift; клавишу можно изменить в управлении Minecraft.

Разработка: **[2twofactorauth3-star](https://github.com/2twofactorauth3-star) + [OpenAI Codex](https://openai.com/codex/)**. ToolVisuals создаётся с помощью ИИ (AI-assisted).

| Minecraft | Java | Fabric Loader | Клиентский JAR |
| --- | --- | --- | --- |
| 26.3 | 25 | 0.19.5+ | ToolVisuals-1.4.3+fabric-26.3.jar |
| 1.21.11 | 21 | 0.19.2+ | ToolVisuals-1.4.3+fabric-1.21.11.jar |
| 1.21.4 | 21 | 0.17.2+ | ToolVisuals-1.4.3+fabric-1.21.4.jar |

Установите Fabric Loader из таблицы или новее и один JAR под свою версию Minecraft. Fabric API и зависимости уже включены в готовые клиентские сборки.

Локальные команды поддерживают `.toolvisuals` и `.toolvisual`, с автодополнением по Tab. Включённый модуль GPS принимает `.toolvisuals gps X Y Z [мир]`; без мира метка работает в любой локации, `gps off` снимает активные цели, `gps list` открывает сохранённые метки.

Переключение серверных Java-протоколов доступно от **1.7.2 до нативной версии выбранной сборки**: 1.21.4, 1.21.11 или 26.3.

[ToolLauncher](launcher/README.md) — Windows-лаунчер с тремя сборками ToolVisuals, установкой игры и Java, отдельными профилями, каталогом модов и управлением аккаунтами.

Для серверной синхронизации плащей, косметики, эмоций, инвентарей друзей и сетевых мини-игр используется плагин ToolVisuals для Paper/Folia. Инвентарь доступен взаимным друзьям с включённым FriendsList у обоих. По умолчанию ХП, броня и инвентарь включены, инвентарь показан сеткой; режим и отображаемые данные меняются в настройках FriendsList и разделе «Друзья». Без плагина доступны известные клиенту ХП и броня находящихся рядом друзей.

В сборки входят оптимизации Sodium, ImmediatelyFast, EntityCulling, Lithium, FerriteCore и другие совместимые компоненты. Состав каждой версии закреплён в манифестах сборки; лицензии перечислены в [NOTICE](NOTICE).

## HolyWorld

На HolyWorld часть функций автоматически отключается с учётом ограничений сервера. Эти ограничения действуют в текущем подключении.

| Недоступно | Почему |
| --- | --- |
| ElytraSwap | Автоматическая смена экипировки; отдельно упомянута в правилах сервера. |
| ProjectilePrediction | Прогноз траекторий Trajectories / Predict указан в правилах Лайта и Альфа СМП. Применяется единое ограничение на HolyWorld. |
| CrystalOptimizer | Предсказание разрушения кристаллов до подтверждения сервера; пример запрещённого преимущества в PvP. |
| TapeMouse | Автоматическое повторение игровых действий, включая клики атаки. |
| AuctionHelper | Автоматизация торговли, команд и действий с инвентарём. |
| Replay | Запись повторов содержит пакеты чанков и данные мира; правила запрещают скачивание мира. |
| FastExp | Предосторожность до отдельного согласования: меняет задержку использования предмета и может влиять на PvP. |
| BuffTracker | Предосторожность до отдельного согласования: показывает рассчитанные эффекты других игроков. |
| TargetESP | Предосторожность до согласования: выделение цели может быть отнесено к ESP; скрытые игроки не должны раскрываться. |
| ChunkAnimator | Предосторожность до согласования: переход появления геометрии может временно открывать вид за стеной. |
| NoFluid | Предосторожность до согласования: снимает ограничение видимости под водой и в лаве. |
| ResourcePackSpoofer | Предосторожность до согласования: обходит фактическую установку серверного ресурспака. |
| Keybinds | Предосторожность до согласования командных и чат-макросов. Ванильная настройка клавиш остаётся доступной. |
| ToolPresents | Предосторожность: помощник отдельного события ToolRise содержит автоматическое выполнение команды перехода. |
| NoRender: туман и подводный оверлей | Закрывают альтернативный способ получить отключённый эффект NoFluid. Остальные фильтры управляются отдельно через API. |

Пункты с пометкой «предосторожность» отключены в ToolVisuals до отдельного согласования. Сервер может дополнительно ограничивать другие функции.

**ToolVisuals пока не объявлен одобренным клиентом HolyWorld.**

Источники: [требования к визуалам](https://mods.holyworld.me/visuals), [правила Лайта](https://github.com/HolyWorldMC/wiki/blob/main/docs/lite-anarchy/rules.md), [правила Прайма](https://github.com/HolyWorldMC/wiki/blob/main/docs/prime-anarchy/rules.md), [правила Альфа СМП](https://github.com/HolyWorldMC/wiki/blob/main/docs/alpha-smp/rules.md).

## Сборка

Нужны JDK 25, JDK 21, Python 3.10 или новее и доступ к интернету. Перед подготовкой укажите JDK 25 в `JAVA_HOME` или `PATH`.

```shell
python build-tools/dependencies.py
./gradlew build
```

На Windows используйте `py -3 build-tools/dependencies.py` и `gradlew.bat build`. Если команда `python` недоступна, передайте Gradle путь к Python через `-PpythonExecutable=путь`.

Три клиентских JAR появятся в `build/libs`. Для отдельной версии: `./gradlew :minecraft1214:build` или `./gradlew :minecraft12111:build`. Команда `./gradlew release` дополнительно соберёт серверный плагин `ToolVisualsPlugin-1.4.3.jar` для Paper/Folia. Он нужен для серверной синхронизации поддерживаемых социальных функций.

Windows-помощник MusicHUD собирается командой `python native/music/windows/build.py` на Windows 10/11.
