# ToolVisuals Protocols

Компонент переключения Java-протоколов на основе ViaFabricPlus, автоматически включённый в клиентский JAR ToolVisuals.

Реализация находится в `src/targets/<Minecraft>`: Java-код, API, визуальные адаптеры и ресурсы для каждой нативной версии. Общие правила выбора протокола и подключение меню находятся в `src/shared`. Компонент собирается из этих исходников. `upstream.json` хранит их происхождение; `libraries.json`, `toolchain.json` и `game-inputs.json` закрепляют библиотеки, инструменты и официальные входные данные Minecraft с контрольными суммами.

Выбор протокола открывает меню ToolVisuals. Диапазон задаётся общим `ProtocolPolicy`: от 1.7.2 до нативной версии сборки. Этот диапазон применяется также к сохранённым значениям и версиям отдельных серверов.

Сначала выполните из корня проекта `python build-tools/dependencies.py` с JDK 25 или новее в JAVA_HOME или PATH. Подготовка скачивает закреплённые библиотеки, подготавливает классы Minecraft и собирает компонент до конфигурации Loom. Затем доступны `./gradlew :viafabricplusFork:fork263`, `:viafabricplusFork:fork12111` или `:viafabricplusFork:fork1214`; общая команда `./gradlew build` собирает клиентские JAR. Результаты и промежуточный API для компиляции находятся в `build/components/viafabricplus`.

Внутренний манифест содержит происхождение, хеш дерева исходников, число скомпилированных классов и контрольную сумму API. ZIP-записи имеют постоянные порядок и время. Параллельные запуски сборщика согласуются через файловую блокировку.

Исходники 1.21.11 используют официальные имена Minecraft, а 1.21.4 — Yarn 1.21.4+build.8. После компиляции TinyRemapper с расширением Mixin преобразует код в intermediary, включая Shadow, Accessor, Invoker и точки внедрения. Данные доступа в ресурсах предназначены для runtime; для компиляции они переводятся в соответствующее пространство имён. Это обычная часть сборки исходников для обфусцированных версий Minecraft.

Условия GPL ViaFabricPlus и ViaLoader и исходные уведомления авторов сохранены в `COPYING`, `NOTICE` и `ATTRIBUTION`, а также внутри компонента. Лицензии вложенных библиотек сохраняются в их архивах. ViaVersion, ViaBackwards и ViaLegacy — отдельные закреплённые библиотеки перевода Java-протоколов. Код компонента сопровождается в этом проекте.
